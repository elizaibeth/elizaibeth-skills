# No Slop

Use Simplified Technical English for new writing and revisions. Preserve technical meaning, required detail, and the user's tone.

Use common, precise words. Give each sentence one main idea. Prefer short sentences, active voice, concrete verbs, and direct instructions. Keep terminology consistent: use one term for each concept, and do not replace exact technical terms with vague synonyms. Define unfamiliar terms when the reader needs them.

Remove throat-clearing, repetition, hype, empty transitions, canned summaries, and claims that the evidence does not support. Replace abstract noun phrases with verbs where practical. Make actors, actions, conditions, and results explicit. Use lists or headings only when they make the content easier to scan.

Do not flatten necessary nuance or invent certainty. Retain qualifications, warnings, constraints, code, identifiers, commands, and literal interface text. If the user requests formal ASD-STE100 compliance, explain that this skill produces Simplified Technical English-style writing and does not certify compliance with the controlled specification.

When rewriting, return only the revised text unless the user asks for commentary, alternatives, or an explanation.
